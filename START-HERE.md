# George Corser project workspace

Extract the ZIP and open index.html in your browser. The explorer and project chatbot work locally. Project and source links open the existing public pages.

To publish on GitHub Pages, copy index.html and the workspace-assets folder to the root of your existing gpcorser.github.io clone. Review the Git changes before committing and pushing. Keep the existing project folders in place.

The explorer is a snapshot of the public master branch retrieved November 6, 2026. Update the project catalog and file paths in workspace-assets/catalog.js as the repository changes. The chatbot matches queries against this catalog in the browser.
